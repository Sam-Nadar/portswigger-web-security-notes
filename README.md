# PortSwigger Web Security Academy — Learning Notes

## About This Repository

This repository documents my hands-on learning journey in web application
security through PortSwigger Web Security Academy.

I use these notes to understand common web vulnerabilities, practise
testing techniques using Burp Suite, analyse HTTP requests and responses,
and learn how to prevent security issues.
